# SRE Foundation Standards

The `docs/sre/standards/` directory contains living documentation for the SRE Foundation slice. These files define:

1. A **code review checklist** with SRE invariants.
2. **ADR and runbook templates** with PDPA/LHDN compliance metadata.
3. **CI quality gates** that guard against unsafe SRE changes.
4. **Handoff templates** for observability, SLOs, incident response, and deployment.
5. A **validation script** that ensures all required artifacts are present and formatted.

> The goal is to make SRE delivery auditable and reproducible.

See each artifact for detailed specifications.
