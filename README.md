# Accounting-AI-Software

🏢 Project Overview
Accounting AI Software - A comprehensive AI-powered accounting platform for Malaysian SMEs (RM300k-RM25m turnover) that integrates compliance (MyInvois e-invoicing, SST, statutory payroll) directly into the core product. The solution enables self-serve onboarding, AI-assisted document capture, and a readiness view for filings, while supporting accountant collaboration.

Hosted in: Azure Malaysia with PDPA-by-design security
Launch: MVP within 3 weeks
